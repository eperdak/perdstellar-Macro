## Features
- Improved biome detection without OCR
- Anti-AFK System
- Auto-reconnection to private server using dedicated URL

## Installation
- Go to [releases](https://github.com/eperdak/perdstellar-Macro/releases/latest), choose the latest version and download the perdstellarMacro.exe! You can also just click [here](https://github.com/eperdak/perdstellar-Macro/releases/download/v1.0-beta.1/perdstellarMacro.exe) to download the latest release automatically.

## Important
### Windows Defender / SmartScreen Notice
- Since this project is open-source and not signed with an expensive digital certificate, Windows Defender or Chrome may trigger a False Positive warning.If Chrome / Edge blocks the download: Click the three dots next to the download -> Keep -> Keep anyway.
- If Windows SmartScreen blocks execution: Click More info -> Run anyway. You can inspect the full source code in this repository.
